// OPERATOR

Who's behind the bench

CAK3D builds tools for the signals nobody else is looking at. Weeknights it's a soldering iron and an ESP32; weekends it's a drive with the radios running, harvesting the air into a map. The work leans cyberpunk and a little gamified — leaderboards, territory, badges — because data is more fun when it's a game.

Everything here is field-tested: if it can't survive a real drive, it doesn't ship.
