// HOW IT'S MEASURED

Where the numbers come from

DOWNLOADS

Every APK, firmware image and Windows build attached to a GitHub release, counted per version.

VISITS

Repo page views from GitHub, plus web app visits once Vercel Web Analytics is on.

LIVE USE

Apps send one anonymous "opened" ping (app, platform, version, a random install ID), giving daily and weekly active users. No names, no locations.
