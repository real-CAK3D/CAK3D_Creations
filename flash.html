// SOLDER · CONNECT · FLASH

The Flash Bench

Put CAK3D firmware on a board straight from the browser — no IDE, no command line.

Plug the board in by USB, hit Flash, pick the port. The board tells the page which chip it is, and the page only lets through firmware that matches — so no board ever gets the wrong firmware.

// USB · ESP32 FAMILY

Flash over USB

These run on ESP32 chips and flash over a USB-serial cable. Each card names the exact board it was built for.

⛊ The board-match guard. When you connect, the flasher reads the chip inside your board and refuses any image built for a different chip. Heads-up where it can't decide for you: two builds share the ESP32-C5 chip — Biscuit and wtBLEep — so the chip check passes for both. Pick by the board name on the card, not just the chip.
// SD CARD · RASPBERRY PI

Flash a Pi (SD card)

Raspberry Pi builds boot from an SD card image — and a browser can't write a raw disk image to an SD card safely, so these don't flash here. Write the image with the free Raspberry Pi Imager instead; it's two minutes.

How to write any Pi image
Download Raspberry Pi Imager → Choose OS → Use custom → pick the downloaded .img (or .img.xz) → Choose Storage → your SD card → Write. Then put the card in the Pi and power up.
